<summary><strong>01 | Overview & Repository Information</strong></summary>

## About This Repository

This repository contains programming logic exercises and flowchart projects developed as part of **CPT 167 – Introduction to Programming Logic** at Tri-County Technical College.

Projects were created using **RAPTOR (Rapid Algorithmic Prototyping Tool)** to explore fundamental programming concepts, algorithm development, logical operations, and structured problem-solving.

The exercises demonstrate how programming instructions, decisions, and repetitive processes can be represented visually before translating them into traditional programming languages.

This repository also serves as an academic portfolio documenting practical experience with algorithmic thinking and visual program development.

### Repository Objectives

- Demonstrate foundational programming logic.
- Document algorithm development and problem-solving techniques.
- Illustrate conditional statements and decision structures.
- Demonstrate repetition and iterative processes.
- Explore modular programming through subprogram calls.
- Maintain examples of academic programming exercises.

</details>

<summary><strong>03 | Repository Structure & File Dependencies</strong></summary>

## Project Organization

All primary RAPTOR flowcharts and associated supporting files are maintained in the `main/flowcharts/` directory.

Some projects utilize separate RAPTOR files as external programs or subprograms called by a primary flowchart. These supporting files are dependencies and must remain accessible at the file paths specified within the calling flowchart.

### Directory Layout

```text
Repository/
│
├── README.md
│
├── assets/
│   └── Banner.png
│
└── main/
    └── flowcharts/
        ├── Project-01.rap
        ├── Project-02.rap
        ├── Project-03.rap
        │
        ├── Supporting-Program-01.rap
        ├── Supporting-Program-02.rap
        │
        └── ...
```

### File Formats

| Extension | Description |
|:---|:---|
| `.rap` | Native RAPTOR flowchart and program files |
| `.png` | Flowchart screenshots and visual references |
| `.jpg` | Image previews |
| `.md` | Markdown documentation |

### File Dependencies & Path Requirements

<blockquote>
<strong>IMPORTANT:</strong> Certain flowcharts depend on external RAPTOR files to execute correctly. The directory structure and file paths specified within each calling flowchart must be preserved.
</blockquote>

- Keep associated `.rap` files in their designated directories.
- Preserve the complete repository directory structure when downloading or cloning.
- Verify the file path specified in each flowchart's Call statement.
- Ensure referenced supporting programs exist at their expected locations.
- Update file references if supporting files are moved or renamed.
- Include all required dependencies when sharing or distributing an individual project.

**Failure to maintain the required file paths or supporting files may result in unsuccessful program calls or execution errors.**

## Viewing Flowcharts

**RAPTOR must be installed to open, view, modify, and execute the native `.rap` files.**

GitHub does not natively render RAPTOR project files as interactive flowcharts.

<div align="center">

<a href="https://raptor.martincarlisle.com/">
  <img src="https://img.shields.io/badge/DOWNLOAD-RAPTOR-00B4D8?style=for-the-badge&logo=windows&logoColor=white" alt="Download RAPTOR">
</a>

<p><sub>Official RAPTOR download website</sub></p>

</div>

### Getting Started

1. Download and install RAPTOR from the official website.
2. Clone or download the complete repository.
3. Navigate to `main/flowcharts/`.
4. Launch RAPTOR.
5. Open the desired primary `.rap` flowchart.
6. Verify that all required supporting programs are available at their specified file paths.
7. Execute the flowchart within RAPTOR.

### Cloning the Repository Using Git

```bash
git clone https://github.com/CypheriumNexus/RAPTOR-Flowcharts.git
```

Navigate to the project directory:

```bash
cd RAPTOR-Flowcharts/main/flowcharts
```

Open the desired `.rap` file through the RAPTOR application.

<blockquote>
<strong>Note:</strong> Downloading an individual flowchart without its required supporting files may prevent certain program calls or subprograms from executing.
</blockquote>
